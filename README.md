# BDA Digital Advertising Budget Optimizer

## Project Overview
This project uses Big Data Analytics techniques to analyze digital advertising performance and recommend marketing budget allocation across different advertising platforms.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Apache Spark (PySpark)
- Jupyter Notebook

## Key Features
- Generates synthetic advertising datasets.
- Analyzes Facebook, Instagram, Google, TikTok, and YouTube advertising performance.
- Calculates CTR, CPC, CPA, Conversion Rate, and ROAS.
- Compares MapReduce simulation and Apache Spark processing performance.
- Tests datasets containing 10K, 100K, 1M, and 10M records.
- Identifies the highest-ROAS advertising platform.
- Recommends advertising budget allocation based on ROAS.
- Visualizes results using bar charts, line graphs, and pie charts.

## How to Run
1. Download the Jupyter Notebook.
2. Open it in Jupyter Notebook or Google Colab.
3. Install the required Python libraries.
4. Run the cells sequentially.

## Project Note
The dataset is synthetically generated for demonstration and educational purposes. The 10-million-record processing stages may require substantial memory and processing resources.
